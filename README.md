# 🚌 Bus Request Generator

CLI-утилита на Python для автоматической генерации официальных заявок на выделение автобуса в формате PDF. Проект создан для минимизации рутинного ручного ввода при оформлении регулярных поездок учебных групп или подразделений.

---

## 💡 Принцип работы

1. При первом запуске программа автоматически считывает (или создает с демо-данными) файл конфигурации `config.json`.
2. Скрипт запрашивает дату поездки в формате `ДДММГГГГ` (например, `20102026` превратится в `20.10.2026`).
3. Вам предлагается выбрать сценарий:
   - **Стандартный режим (нажмите `Enter`):** Подтягивает дефолтные маршруты и данные ответственного из конфига, запрашивает только количество занятий (1–4) и число пассажиров. Время обратного выезда подставляется автоматически из расписания.
   - **Ручной режим (введите `н`):** Позволяет кастомизировать название группы, ФИО ответственного, телефон, пункты отправления/назначения и время. Все введенные изменения автоматически сохраняются в `config.json` на будущее.
4. Программа автоматически прибавляет время в пути к моменту отправления, формирует документ с поддержкой кириллицы и сохраняет готовый PDF в папку `output/`.

---

## ✨ Основные особенности

* **PDF-генерация:** Использует библиотеку `fpdf2` для создания строго структурированных документов с поддержкой кириллицы (благодаря шрифтам DejaVu).
* **Внешняя конфигурация (`config.json`):** Все стандартные параметры (название подразделения, данные ответственного, дефолтные маршруты и расписание) вынесены во внешний файл конфигурации.
* **Умный CLI-ввод:** 
  * Автоматическое форматирование даты (ввод `20102026` превращается в `20.10.2026`).
  * Слитный ввод времени (ввод `0810` превращается в `08:10`).
* **Два режима работы:**
  * **Стандартный:** Быстрая генерация в один клик. Выезд туда в фиксированное время, авторасчет времени обратно на основе количества занятий (1–4 занятия).
  * **Ручной:** Полная кастомизация времени, маршрутов и данных ответственного с возможностью сохранения в конфиг.
* **Автоматический расчет:** Программа сама прибавляет заданное время в пути (например, 1 час 20 минут) к моменту отправления для точного вычисления времени прибытия.
